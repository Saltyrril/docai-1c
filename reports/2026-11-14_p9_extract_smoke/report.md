## Наблюдения

- **Качество не мерилось** (это P11), но по ходу видно: на текстовом пути оба УПД определены как `vat_invoice`
  (в шапке УПД есть «Счёт-фактура №»), в первом пробном запуске дата «06.02.2025» превратилась в «0602-02-20».
  Сравнение с эталоном — в P11.
- **Модель не помещается в GPU целиком.** Ollama 0.40.16 видит свободными 3,2 ГиБ из 4 (журнал:
  `available="2.8 GiB" free="3.2 GiB"`) и кладёт на GPU 17–18 слоёв из 25 (`ollama ps`: 37%/63% CPU/GPU).
  От `num_ctx` это не зависит: при 4096, 6144 и 8192 — 35–37% на CPU, около 10 токенов/с на генерацию.
  Отсюда время: в среднем 136 с на документ по тексту и 188 с по vision (генерация — почти всё время).
- **Пик VRAM по nvidia-smi занижен.** В простое `memory.used` = 0 МиБ, `memory.free` = 3964 МиБ, а CUDA
  (по журналу Ollama) видит свободными 3,2 ГиБ: около 0,7 ГиБ занимают другие программы (рабочий стол
  Windows в режиме WDDM), и nvidia-smi их не показывает. Даже с этой поправкой пик ≈ 2,56 + 0,7 ≈ 3,3 ГиБ < 3,8.
- GPU работал с ограничением по мощности и температуре (`clocks_event_reasons.active` = 0x24), поэтому
  скорость генерации плавала от ~10 до ~30 токенов/с между запусками.
- Путь xml не использует GPU; пик VRAM в его строках — это модель, которая ещё оставалась в памяти
  после предыдущих запусков (`keep_alive` 5m).
- **OCR (Tesseract 5.4.0, `rus`, psm 3):** распознавание всех 13 страниц — 21 с на CPU, остальное время — LLM.
  В первом прогоне `00051_vat_invoice` не собрался: ответ на весь двухстраничный текст обрезан по
  `num_predict=4096`. После этого в конвейер добавлен повтор по страницам (D37); итог выше — второй прогон.
  У этого документа и запрос по странице 1 упёрся в 4096 токенов (вероятно, модель зациклилась на шумном
  тексте OCR), поэтому документ собран только по странице 2: 4 строки из 21, тип `upd` вместо `vat_invoice`.
  JSON валиден, ошибка страницы записана в `errors`. Разбор — в P11.
- Путь text не перепрогонялся после добавления повтора по страницам: в его прогоне обрезанных ответов не было,
  а без них код пути не изменился.
