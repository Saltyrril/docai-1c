## Как повторить

```powershell
uv run docai rag build      # корпус, реестр и 200 вопросов в data/rag/ (seed 42, ~2 с)
```

### Насколько вопросы «совпадают по словам» с источником

Доля основ слов вопроса (первые 5 букв слов от 4 букв), которые встречаются в цитате источника:

| Категория | Пересечение |
| --- | ---: |
| простой факт | 0,41 |
| несколько условий | 0,41 |
| доп. соглашение | 0,31 |
| сравнение двух договоров | 0,26 |
| перефразированный вопрос | 0,23 |

Перефразированные вопросы почти вдвое реже повторяют слова договора — на них поиск по ключевым словам (BM25) должен проседать сильнее, чем по эмбеддингам. Это гипотеза для P22.

## Пример

Договор `K-0097` (подряд), п. 2.2: «Заказчик обязуется произвести оплату Работ не позднее 14 (четырнадцати) рабочих дней со дня подписания акта КС-2 и справки КС-3». Доп. соглашение `K-0097-DS1`, п. 2: «Стороны договорились изложить п. 2.2 Договора в новой редакции: «Заказчик оплачивает выполненные Работы в течение 60 (шестидесяти) рабочих дней …»».

- Вопрос о доп. соглашении (Q122): «Сколько времени у нас есть, чтобы рассчитаться с «Потенциал-Торг» после приёмки работ сейчас?» → эталон 60 рабочих дней, источник `K-0097-DS1#2`, старая редакция `K-0097#2.2` (14 дней) — в `superseded`.
- Тот же договор в сравнении (Q141): «где срок оплаты длиннее» — берётся уже действующее значение 60 дней из соглашения.
