# reports/

Результаты экспериментов. Каждый эксперимент — отдельная папка
`reports/<ГГГГ-ММ-ДД>_<название>/` с файлами:

- `config.yaml` — конфигурация запуска (включая seed);
- `results.json` — метрики в машинном виде;
- `report.md` — короткий отчёт для человека.

Реальные документы и их содержимое сюда не попадают.
