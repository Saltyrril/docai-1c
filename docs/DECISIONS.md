Правки с парами «было → стало» — готовые обучающие примеры для дообучения и метрика «правок на документ» | Очередь в памяти (`queue.Queue`) — теряет задания при перезапуске; Celery/Redis — лишние службы для одного компьютера; рисовать превью по запросу — гонка в pdfium и ожидание в форме 1С; вложенный JSON с типами схемы (числа как `number`) — теряет формат записи и заставляет 1С разбирать вещественные; открыть сервис в локальную сеть — документы не должны уходить с компьютера, а аутентификации нет |
