# Журнал решений

Новые записи добавляются в конец. Для доменных правил (налоги, форматы ФНС, 1С) обязательна ссылка на официальный источник.

| № | Дата | Решение | Почему | Альтернативы |
|---|---|---|---|---|
| D1 | 2026-11-14 | Основная модель — **Qwen3.5-2B, квантизация Q8_0** (`qwen3.5:2b-q8_0` в Ollama, vision-проектор встроен) | Читает русский текст с картинки и отдаёт верный JSON (P0). Пик VRAM 2,53 ГиБ — помещается в 4 ГБ RTX 3050 с запасом под контекст. Q8_0 почти не теряет качество относительно исходных весов, а качество извлечения важнее скорости. Лицензия Apache-2.0 (по `ollama show --license`) | Q4_K_M — быстрее и на ~0,3 ГиБ меньше VRAM, но заметнее теряет точность; останется для сравнения в P14. 0.8B — слабее, но её можно дообучать локально. Модели 4B+ — не помещаются в VRAM вместе с изображением |
| D2 | 2026-11-14 | **Не используем LayoutLMv3** | Токенизатор английский (BPE от RoBERTa), русский текст режется на мелкие куски, качество на кириллице низкое. Лицензия весов CC BY-NC-SA 4.0 — некоммерческая, несовместима с портфолио-проектом, который может стать коммерческим | Vision-LLM (Qwen3.5-2B) — понимает русский и выдаёт JSON сразу; OCR + текстовая LLM — запасной вариант |
| D3 | 2026-11-14 | **Не берём EnterpriseRAG-Bench как данные** для RAG | По оценке владельца: это синтетика про американскую IT-компанию — не русские договоры и не наш домен; условия использования запрещают обучение на этих данных | Собственный корпус синтетических договоров на русском (P21) с размеченными вопросами и эталонными цитатами |
| D4 | 2026-11-14 | **Основной датасет — синтетические документы** (`src/docai/synth` + `render`) | Открытого размеченного датасета российских первичных документов нет. Реальные документы конфиденциальны и их мало. Синтетика даёт точную эталонную разметку, контроль над разнообразием (ставки НДС, ИП/юрлица, искажения сканов) и воспроизводимость по seed | Ручная разметка реальных документов — дорого и нельзя публиковать; используется только для итоговой локальной проверки (P24). Публичные англоязычные датасеты (FUNSD, CORD и т. п.) — другой язык и другие формы |
| D5 | 2026-11-14 | Инструменты разработки: **ruff** (линтер + форматтер), **pytest**, **pre-commit**; ruff в pre-commit запускается через `uv run` | Одна версия ruff из `uv.lock` и в редакторе, и в хуке. Все инструменты под MIT. Правила ruff RUF001–003 отключены: кириллица в строках и комментариях — норма проекта | black + isort + flake8 — три инструмента вместо одного и медленнее |
| D6 | 2026-11-14 | Пакет импортируется как `docai`, дистрибутив называется `docai-1c`; сборка через `uv_build` | Короткое имя для импорта, `src/`-раскладка не даёт случайно импортировать код в обход установки | hatchling/setuptools — лишняя зависимость при наличии uv |
